# Contributing

Thanks for helping! Bug reports and pull requests are welcome.

## Licence of contributions

- Contributions to the app are made under the same licence as the app (Apache License 2.0 with the Commons Clause, see
  [LICENSE](LICENSE)); contributions to a node pack in `src-tauri/resources/plugins/*/nodes/` under that pack's licence (GPL-3.0).
- By contributing you also allow the maintainer (7err4) to relicense your contribution together with the project under the plain
  Apache License 2.0 or another OSI-approved open source licence (for example, dropping the Commons Clause if the project is no
  longer maintained).
- Only contribute code you wrote yourself or may contribute under these terms.

## Content

The repository stays safe for work: no explicit images, prompts or example content.
